# 客服工单处理 Agent — 需求文档

## 业务背景

客服团队每天处理约 200 张工单，其中 60% 是重复性劳动：查物流状态、改收货地址、退差价、修改订单备注等。这类工单规则明确、变化少，完全可由 Agent 自动处理，释放人力去解决真正需要判断力的复杂问题。

## 自动化目标

用 LLM Agent 自动处理重复性工单，流程分三步：

1. **意图分类** — 识别工单属于订单、物流、售后哪一类
2. **信息提取** — 从工单内容提取关键信息（订单号、运单号、金额等）
3. **执行操作** — 调用对应工具完成处理；复杂工单自动转人工

## 成功指标

| 指标 | 含义 | 目标 |
|------|------|------|
| 自动处理成功率 | Agent 独立完成且结果正确的比例 | ≥ 80% |
| 转人工率 | 判定需要人工介入的比例 | ≤ 20% |
| 分类准确率 | 意图分类正确的比例 | ≥ 95% |

## MVP 范围

### 覆盖工单类型
- **订单类**：查订单状态、改收货地址、修改备注
- **物流类**：查物流轨迹、催派送
- **售后类**：退差价、换货申请

### 不做什么
- 不做语音工单（只处理文本）
- 不做多轮对话界面（单次请求-响应）
- 不接真实业务系统（全部用 mock 数据模拟）
- 不做权限与用户认证
- 不做花哨功能，稳定性和可排查性优先
